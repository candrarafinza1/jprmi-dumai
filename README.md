# Website JPRMI Kota Dumai

Website statis (HTML) untuk Jaringan Pemuda dan Remaja Masjid Indonesia (JPRMI) Kota Dumai.

## Mengubah isi
Buka `index.html`, cari teks dalam [KURUNG SIKU] lalu ganti dengan data asli (jumlah anggota, visi-misi, agenda, alamat, nomor WhatsApp, foto).

## Deploy ke Vercel
1. Masuk ke vercel.com dengan akun GitHub.
2. Add New → Project → pilih repository ini → Import.
3. Framework Preset: **Other**. Tidak perlu build command. Klik **Deploy**.
Setiap perubahan yang di-push ke GitHub akan otomatis tayang ulang.
